My Journey into Coding

Starting my journey into coding has been both exciting and challenging. At first, seeing all the different tags and lines of code looked confusing, but with practice, I gradually started understanding how websites are built. I began with HTML, learning how to create the structure of a webpage using headings, paragraphs, links, images, lists, forms, and other elements. One of my favourite parts has been seeing my code come to life in the browser. I have also learned how to connect different pages together, add pictures and videos, and create simple forms using input fields. Every new thing I learn makes me more curious about what I can create next. Now, I'm getting ready to start CSS, which will help me make my webpages look more attractive and organized. I'm excited to learn how colours, fonts, spacing, layouts, and other designs can transform a simple HTML page. Coding has taught me that you don't have to understand everything immediately. Sometimes you just need to keep practicing, make mistakes, fix them, and try again. This is only the beginning of my web-development journey.
