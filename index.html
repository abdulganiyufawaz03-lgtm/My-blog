My Experience Learning Web Development

Learning web development has been an interesting journey. I started by learning HTML and understanding how webpages are created.

When I first opened a code editor, looking at tags and angle brackets felt a bit overwhelming. However, as i started writing basics elements like headings, paragraphs, and links, I realized that HTML is simply the backbone that gives every webpage its skeleton and structure.

What I Have Learned

So far, These are what I've learnt:

  • How to create webpages with HTML.
  • How to add images.
  • How to create links between pages.
  • How to use forms and input fields.
  • How to create clickable navigations links.
  • How to list items to keep information neat and readable.

Building this blog using strictly HTML has given me a strong foundation. My next target is to keep practicing markup structure until it becomes second nature, and then I will take the leap into learning CSS so i can add styling, custom colors, and unique layouts to my pages!.
